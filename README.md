A program that writes one haiku about debugging to `/output/entry.txt`,
for the make.fun competition
[Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605).

Run it with Python 3:

```
python3 main.py
```

It writes the haiku below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The haiku is 78 characters, inside the 1 to 200 gate, in the
5-7-5 syllable shape.

## The haiku

```
Cold coffee, warm screen
the cursor waits where it stopped
the bug outlived me
```

Syllables: 5-7-5, seventeen in total. The picture at the centre is
concrete: cold coffee, a warm screen, a cursor that stopped where it was
left. The last line turns it: the bug outlived the debugger.
